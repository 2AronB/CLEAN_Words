# Original crossword inputs

`pilot.tsv` is the authoritative original editorial source: uppercase answer and
two tab-separated original clues using the same intended sense. It consolidates
the initial `base.tsv`, `root-five.tsv` and `root-short.tsv` working drafts,
deduplicating answer texts and correcting AGO/ACORN/ALBUM wording. The drafts are
historical authoring material, not separately loaded runtime banks.

Original CLEAN Words AI-authored content, 2026-10-26. No external clue resource,
publisher puzzle, scraper, external SDK, permission or runtime service is used.
No third-party attribution license is required; the app credits still disclose
this original finite pilot and its lack of human editorial review. Original
wording is not a claim that every clue is novel or calibrated.

Run from repository root:

```
node tools/generation/crossword/prepare-bank.mjs
node tools/generation/crossword/prepare-bank.mjs --check
node tools/generation/crossword/check-fill.mjs
```

Preparation generates deterministic blank masks, validates geometry and keeps
16 fillable masks for each size after bounded author-time search with the real
pilot. It emits the provenance JSON asset, compiled typed Kotlin source and hashes.
No completed-grid catalog is emitted or used by the app. `--check` verifies exact
generated bytes without writing. Independent JavaScript fill smoke separately
scans all retained masks and stores diagnostic words in a development report.

The Kotlin tests perform authoritative pinned-seed runtime qualification and an
independent scanner verifies actual frozen fills, numbering, crossings and clues.
`qualification.txt` contains final test output when supplied by the coordinated
primary build. Module design/results live under
`app/src/main/java/dev/clean/words/generators/crossword/`.
